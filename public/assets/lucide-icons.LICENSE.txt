LibreFlow vendored icon provenance
=================================

Source package: lucide-static@0.468.0
Source artifact: https://registry.npmjs.org/lucide-static/-/lucide-static-0.468.0.tgz
Source package path: package/icons/<name>.svg
License reference: https://lucide.dev/license

The path registry in public/js/icons.js was generated with
scripts/generate-libreflow-icons.js from the unpacked package/icons directory.
The generator map records every source filename. Annotation aliases use
upstream 2D geometry: box -> rectangle-horizontal, rotatedBox -> the same
rectangle-horizontal rotated 18 degrees around (12,12), polygon -> pentagon,
point -> crosshair, mask -> brush, polyline -> waypoints, and skeleton ->
network. All other names map directly to a package icon filename.
