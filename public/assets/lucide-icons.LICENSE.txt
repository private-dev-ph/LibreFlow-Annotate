LibreFlow shared icon subset
============================

The inline SVG path data in public/js/icons.js is vendored from the
lucide-static package, version 0.468.0 (source: https://www.npmjs.com/package/lucide-static).
License reference: https://lucide.dev/license
Only the paths needed by LibreFlow are included; there is no runtime package
or network request.
