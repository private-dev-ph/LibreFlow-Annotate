Connect a local AI tool

Run the LibreFlow MCP server on the same machine as your AI tool.

  1. 1
    Start the local bridgenode /absolute/path/bin/libreflow-mcp.js
  2. 2
    Set the endpointLIBREFLOW_MCP_URL=http://127.0.0.1:6769
  3. 3
    Add your one-time tokenLIBREFLOW_MCP_TOKEN=your-token-here

Only the selected projects and checked permissions are shared with your chosen AI service. Image previews disclose image contents. Original files, model weights, and write access are not included. Revoking access stops future reads; it cannot retract data already received.
